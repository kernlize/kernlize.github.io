          event: NostrEvent,
          before: NostrEvent | undefined,
          applet: AppletIdentity,

      Describe a write the shell is asked to sign as what it changes.

      Profiles diff field by field; follow, relay and list changes count what was added and removed and name the first few entries by hex prefix; deletions list what disappears. Those kinds are destructive because they replace or erase the account's public record. Everything else is routine and shows a content preview. Nothing here is protocol vocabulary the user has to know, and nothing secret is copied out of the event.

      Parameters

      • event: NostrEvent

        The event to be signed.

      • before: NostrEvent | undefined

        The current version of the replaceable event, when known.

      • applet: AppletIdentity

        The applet asking.

      Returns ConsentSummary

      The summary the host renders.

      Example

      describeChange(kind3Event, currentFollows, identity).lines[0];
      // { label: 'Follows added', after: '1: 3bf0c63f…' }
