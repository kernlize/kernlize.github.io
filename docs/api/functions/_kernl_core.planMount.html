    Function planMount

    • planMount(options: PlanMountOptions): MountPlan

      Build everything mountApplet needs, without touching the DOM.

      The environment is kehto's resolveShellEnvironment, so it is the live domains narrowed by the host's capabilities.resolveEnvironment (kernl's grants). The CSP is the guard's zero-network profile plus its Trusted Types directives, inserted first in <head> by prepareNappletSrcdoc along with the mandatory namespace prelude and then the guard's frame lock. Markup that declares a nested frame is refused before any of that (D-014). missingRequired lists what the applet asked for and will not get, so the host can warn before mounting.

      Parameters

      • options: PlanMountOptions

        Summary, verified HTML, adapter, guard profile and window id.

      Returns MountPlan

      A plan whose srcdoc is ready to assign.

      Throws

      Error('denied:nested-frame') when the verified markup declares a frame element.

      Example

      const plan = planMount({ summary, indexHtml, adapter, guardProfile: 'strict', windowId: 'w1' });
      plan.sandbox; // 'allow-scripts'
