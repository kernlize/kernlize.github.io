    Function createIngressGuard

    • createIngressGuard(options: IngressGuardOptions): IngressGuard

      Create the flood control that sits in front of the kehto bridge.

      Each window has a token bucket of ingressBurst per second. When it is empty, envelopes queue (defer) up to ingressQueue and are released by drain as tokens refill; past the queue they are rejected. A window that sends quarantineThreshold messages inside ten seconds, or fetches more than hiddenResourceAllowance resources while hidden, is quarantined until the user releases it. Oversized envelopes are rejected outright.

      The guard emits an event for every disposition other than pass, so the user can see what an applet tried to do (D-003).

      Parameters

      • options: IngressGuardOptions

        Configuration, time source, event sink and drain batch size.

      Returns IngressGuard

      An ingress guard tracking many windows.

      Example

      const guard = createIngressGuard({ config: createGuardConfig('strict') });
      guard.admit('w1', 'chat', { type: 'relay.subscribe' }, { visible: true, focused: true }); // 'pass'
