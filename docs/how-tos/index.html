How-tos ​

One task per page, with the exact calls. Each assumes you have the kernl source and have run pnpm install && pnpm build (Run the shell); for a guided first pass, start with the tutorials instead.

How-toWhat it does
Change the guard profileSwitch the shell between strict, balanced and relaxed, and what a profile can and cannot change.
Grant and revokeWhat the shell asks when an applet opens, what each answer changes, and the Kernl calls behind the grants panel.
Embed kernl coreImplement KernlHost, call createKernl and mount an applet in an iframe your own page owns.
Add a messaging providerDefine a provider and its backend, and register it in the shell's messaging registry.
Add a bridge backendSupply a backend that turns an unavailable bridge, such as downloads, into a working one.
DeployBuild the site, shell, docs and API reference into one static artifact and publish it to GitHub Pages.
