Error reasons ​

Every failure in the four packages carries a stable reason string with a prefix that says what kind of failure it is. Code matches on the string; the UI maps it to words. This page lists each reason the packages throw or report, collected from packages/*/src.

PrefixMeans
denied:A policy or the user said no. Retrying the same request will not help.
invalid:The input is malformed or names something that does not exist.
unavailable:Something needed is missing or unreachable right now: a backend, a server, a provider.

Thrown reasons are the message of an Error. A few carry a detail after a space (denied:scheme http:), so match on the part before the first space.

Guard event reasons ​

The guard reports each non-pass decision as a GuardEvent with a disposition (defer, reject, quarantine, flag) and one of these reasons. They reach the user through kernl.guard.events$ and the shell's guard panel. The numbers are per profile; see Guard.

ReasonLayerMeaning
flood:burstingress guardMore messages in one second than ingressBurst allows; the message is queued.
flood:queue-fullingress guardThe ingress queue is full; the message is rejected.
flood:quarantineingress guardToo many messages in the rolling window, or any message from a quarantined window. The applet is revoked.
flood:hidden-resourceingress guardA hidden window used up its resource.* allowance. The applet is quarantined and revoked.
size:<class>ingress guard, focus firewallThe envelope is over the size cap for resource:bytes, relay:subscribe or outbox:subscribe.
defer:queue-fullvisibility gateThe hidden window's deferral queue is full. Only the window-level hello passes through the gate (D-012).
rate:<class>focus firewallThe operation class's token bucket is empty, for example rate:relay:publish.
prompt:<ruleId>focus firewallkehto's engine asked for a prompt; the guard treats it as a rejection.

Revocation reasons ​

KernlHost.onRevoked(windowId, reason) receives kehto's revocation reasons (window-message, second-hello, invalid-hello, second-load, port-closed, host) or quarantine when the guard quarantined the window. See Architecture.
